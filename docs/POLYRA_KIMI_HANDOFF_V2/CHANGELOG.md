# Изменения handoff-пакета V2

## Добавлено

N01: обязательные реальные субагенты, проверка tool availability, ограничение четырьмя,
file ownership/dispatch, восемь профилей, интеграционный контроль.

N02: запуск в текущем OpenCode Desktop, сохранение текущей Kimi-конфигурации,
совместимые базовые Markdown-профили, безопасный installer, различение схем docs/v2.

N03: сохранить существующие модели и их IDs, отделить temporary health от capabilities,
исследовать нестабильность и проверить все модели до/после исправлений.

N04: DeepSeek V4 Pro через существующий AlibabaProvider; отдельный text-only профиль,
проверенные особенности effort, сквозной UI/API/access/stream/tools/usage/probe/test scope.

Официальные источники с датой проверки; новая дополнительная приёмка;
44 строки work-item tracker (40 старых findings + 4 новых требования),
10 baseline-строк model regression template.

## Изменено в актуальном KIMI_FIX_PROMPT.txt

Условная фраза «при наличии субагентов» заменена обязательным реальным делегированием
с честным blocked-статусом при технической недоступности.
Обновлён модельный инвариант и добавлена Pro.
Исторический критерий A27 «9 моделей» расширен до минимума 10.
Добавлены N01–N04, Desktop bootstrap, распределение ролей и приёмка V2.

Содержимое остальных A01–A40 сохранено; их доказательства не объявляются
заново проверенными. В новых требованиях уточнена интерпретация transient failures.

## Сохранено без изменений

Все 28 файлов старого audit-пакета в `audit_original/`, включая исходное ТЗ,
исторический prompt, findings, code evidence, файл-за-файлом review,
тестовые логи и диагностические скрипты.

Исходный project ZIP сохранён побайтно как
`reference/AUDITED_SOURCE_SNAPSHOT.zip`; SHA-256:
`37f7f26dc7503319db3b7bc90136f273cde3003a4ebaae54e39157f892ef6294`.

## Не выполнялось

Новые production fixes, новый полный аудит текущего GitHub checkout, запуск
OpenCode Desktop, реальные child sessions и реальные Telegram/Gemini/Alibaba calls.
Проверки этого пакета относятся к целостности документов и безопасной установке
профилей, а не к готовности Telegram-бота.
