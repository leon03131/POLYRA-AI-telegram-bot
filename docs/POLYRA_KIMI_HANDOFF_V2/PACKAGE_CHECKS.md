# Проверки handoff-пакета V2

Проверено при сборке 24.09.2026. Это НЕ новые тесты работоспособности Telegram-бота.

| Проверка | Результат |
|---|---|
| Все 28 файлов прежнего аудита сохранены побайтно | passed |
| Исходный project ZIP совпадает по SHA-256 с audited baseline | passed |
| Вложенный ZIP проходит проверку CRC | passed |
| В актуальном prompt есть все A01–A40 в исходном порядке | passed |
| Текст всех findings сохранён, кроме намеренного расширения A27 с 9 до 10 моделей | passed |
| N01–N04 встроены в актуальный prompt | passed |
| Восемь agent profiles: YAML frontmatter корректен | passed |
| В profiles нет фиксированного model и нет автоматического изменения permissions | passed |
| JSON-файлы читаются; Python installer проходит AST parse | passed |
| Preview installer не создаёт файлы/каталоги | passed |
| Первая установка создаёт восемь profiles и сохраняет исходные config/AGENTS.md | passed |
| Повторная установка идентичных profiles идемпотентна | passed |
| Отличающийся профиль вызывает отказ без установки остальных missing profiles | passed |
| Symlink в destination отклоняется | passed |
| Неподходящий project root отклоняется | passed |

Тесты installer выполнялись в одноразовых тестовых каталогах, а не на проекте
владельца. Были проверены поведение Python-скрипта и структура профилей, а не их
обнаружение установленным OpenCode Desktop. Скрипт намеренно не запускает агентов.

`MANIFEST.json` содержит SHA-256 и размеры всех остальных файлов пакета.
Проверка ZIP/manifest проводится после окончательной упаковки.
Хеши подтверждают целостность состава, но не являются цифровой подписью автора.

## Не выполнялось в этой пересборке

Новый полный аудит текущего checkout; исправление production code; frontend/DB/Docker
приёмка бота; запуск OpenCode Desktop; реальные child sessions; Telegram/Gemini/Alibaba
API calls. Версия Desktop и права пользователя неизвестны.

Новые шаблоны результатов имеют pending/not_started/not_run и не являются
положительным отчётом. Старые результаты 285 passed и прочие сохранены только
как исторические доказательства в `audit_original/`.
