# POLYRA — пакет аудита

Дата: 24 сентября 2026. Объект — предоставленный ZIP, а не автоматически обновляющаяся ветка GitHub. Исходный код не исправлялся.

Начните с **AUDIT.md**. Для передачи разработчику используйте **KIMI_FIX_PROMPT.txt**: это самостоятельное задание с описанием всех 40 пунктов, порядком работ и критериями приёмки. Желательно передать весь пакет, исходный ZIP и первоначальное ТЗ.

| Файл | Содержимое |
|---|---|
| AUDIT.md | Выводы, ограничения проверки и 40 детальных пунктов |
| KIMI_FIX_PROMPT.txt | Готовое задание Kimi на исправление, а не на повторный пересказ аудита |
| FILE_REVIEW.md | Реестр всех 215 файлов, вид проверки, связанные замечания |
| REQUIREMENTS_MATRIX.md | Сопоставление со всеми 58 разделами исходного ТЗ, 0–57 |
| CODE_EVIDENCE.md | Привязанные к строкам фрагменты исходного кода |
| TEST_RESULTS.md | Что действительно запускалось и что не удалось запустить |
| OFFICIAL_SOURCES.md | Использованные официальные внешние источники |
| ORIGINAL_REQUIREMENTS.txt | Копия предоставленного исходного ТЗ |
| findings.json | Те же 40 замечаний в машинно-читаемом виде |
| evidence/ | Логи, инвентаризация, результаты диагностик и offline SQL |
| regressions/ | Диагностические скрипты и инструкция повторения |
| MANIFEST.json | SHA-256 и границы проверенного снимка |

P1/P2/P3 — приоритет исправления, не CVSS. В пакете различаются воспроизведённые дефекты, статические выводы, риски, отсутствующие обязательные функции и дополнительные улучшения. 40 пунктов не означают 40 доказанных уязвимостей.

Диагностики с `reproduced: true` подтверждают наличие ошибки в старом снимке. Это НЕ тесты качества, которые должны оставаться зелёными после исправления. Kimi должен превратить их в регрессионные тесты правильного поведения.
